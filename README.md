# Auto Screen Reader (অটো স্ক্রিন রিডার)

একটি শক্তিশালী অ্যান্ড্রয়েড অ্যাক্সেসিবিলিটি স্ক্রিন রিডার অ্যাপ্লিকেশন যা বাংলা, ইংরেজি, আরবি, হিন্দিসহ যেকোনো ভাষায় মোবাইল অ্যাপ ও স্ক্রিনের উপাদান স্বয়ংক্রিয়ভাবে পড়ে শোনায়।

---

## ⚡ কোনো কেবল ছাড়াই সরাসরি ফোনে এপিকে (APK) ডাউনলোড করার নিয়ম

১. এই প্রজেক্টের ফাইলগুলো গিটহাবে (GitHub) একটি নতুন রিপোজিটরিতে আপলোড করুন।
২. আমাদের দেওয়া **`.github/workflows/build-apk.yml`** স্ক্রিপ্টটি ক্লাউডে স্বয়ংক্রিয়ভাবে রান করবে (১ মিনিট সময় নিবে)।
৩. আপনার GitHub রিপোজিটোরির **"Actions"** ট্যাবে গিয়ে লেটেস্ট বিল্ডে ক্লিক করুন।
৪. নিচে **Artifacts** সেকশনে **`AutoScreenReader-DirectInstall-v1.0`** দেখতে পাবেন।
৫. ফোন দিয়ে ব্রাউজারে লিংকে ট্যাপ করুন — সরাসরি আপনার ফোনে **.apk** ফাইল ডাউনলোড হয়ে যাবে!
৬. ডাউনলোড করা ফাইলটিতে ট্যাপ করলেই ভেসে উঠবে: **"Do you want to install this app?"** -> **Install** এ চাপুন।

---

## 📱 ফোনে ইনস্টল করার পর মাত্র ১টি কাজ:
১. অ্যাপটি ওপেন করে বড় সবুজ বাটনে চাপ দিন: **"অ্যাক্সেসিবিলিটি সার্ভিস চালু করুন"**।
২. ফোনের সেটিংসে তালিকা থেকে **Auto Screen Reader** এর টগলটি অন (**ON**) করে দিন।
৩. কাজ শেষ! স্ক্রিনের ওপর একটি ফ্লোটিং বোতাম চলে আসবে, যা দিয়ে যেকোনো অ্যাপে এক ট্যাপেই লেখা পড়া যাবে।
